# BAD: never make the game look like this

- **"ChatGPT pets":** a few big boxes stuck together (basic cow, red box dragon with stub horns), one flat colour per part, no glow / VFX / particles, no theme, generic silhouette.
- **Generic realistic animals:** a plain orange voxel fox in natural colours with no element and no effects. It reads as a standard Minecraft mob, nothing rare.
- **Dark, moody, hard-to-read worlds:** Steal a Dragon's "before" was a night version. The bright daytime redo was the improvement.
- **Static UI:** windows that just appear, cards that appear all at once, claims with no feedback. See `ui-motion.md`.
- **Flat / minimal / thin UI:** thin fonts, no outlines, pastel or desaturated colours.
