# Scaffold Templates

Substitute `{{NAME}}` with the project name everywhere. Each `## path` heading
below is one file. This exact set was materialized and run on 2026-11-01 with
the pinned versions: `rojo build`, `rojo sourcemap`, `stylua --check src`,
`selene src`, `luau-lsp analyze` all pass (macOS arm64), with an empty project
and with a real system plus a `Packages` folder. Not tested: the CI file on
GitHub, `wally install`, and opening the result in Studio.

## rokit.toml

```toml
[tools]
rojo = "rojo-rbx/rojo@7.7.1"
wally = "UpliftGames/wally@0.3.2"
selene = "Kampfkarren/selene@0.32.0"
stylua = "JohnnyMorganz/StyLua@2.6.0"
luau-lsp = "JohnnyMorganz/luau-lsp@1.70.1"
```

Latest GitHub releases on 2026-11-01. Re-check before pinning:
`curl -s https://api.github.com/repos/<owner>/<repo>/releases/latest`.
Wally 0.3.2 fails on an Apple Silicon Mac without Rosetta ("bad CPU type in
executable"); remove the line if the project has no Wally dependencies.

## default.project.json

```json
{
  "name": "{{NAME}}",
  "emitLegacyScripts": false,
  "tree": {
    "$className": "DataModel",
    "ReplicatedStorage": {
      "Shared": {
        "$path": "src/shared"
      },
      "Client": {
        "$path": "src/client"
      }
    },
    "ServerScriptService": {
      "Server": {
        "$path": "src/server"
      }
    }
  }
}
```

`emitLegacyScripts: false` makes Rojo emit `Script` with `RunContext = Client`
for `*.client.luau` (checked in the built place). The default, `true`, emits a
`LocalScript`, and ReplicatedStorage isn't one of the documented `LocalScript`
containers.

**Add Wally packages only when the project has dependencies.** Every `$path`
must exist or `rojo build` fails, so run `wally install` first, and add to the
matching service:

```json
"ReplicatedStorage": { "Packages": { "$path": "Packages" } },
"ServerScriptService": { "ServerPackages": { "$path": "ServerPackages" } }
```

## .github/workflows/ci.yml

```yaml
name: CI

on:
  push:
    branches: [main]
  pull_request:

permissions:
  contents: read

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7

      # Installs the versions in rokit.toml. The token defaults to github.token.
      - uses: CompeyDev/setup-rokit@v0.2.1
        with:
          cache: "true"

      # Needed only with Wally dependencies, before the Rojo steps:
      # - run: wally install

      - name: Check formatting
        run: stylua --check src

      - name: Lint
        run: selene src

      - name: Generate sourcemap
        run: rojo sourcemap default.project.json --include-non-scripts --output sourcemap.json

      # Same tag as luau-lsp in rokit.toml; bump both together.
      - name: Download Roblox type definitions
        run: >-
          curl -fsSL -o globalTypes.d.luau
          https://raw.githubusercontent.com/JohnnyMorganz/luau-lsp/1.70.1/scripts/globalTypes.d.luau

      - name: Type check
        run: luau-lsp analyze --sourcemap=sourcemap.json --definitions=@roblox=globalTypes.d.luau src

      - name: Build place
        run: rojo build default.project.json --output build.rbxl
```

## README.md

```markdown
# {{NAME}}

Roblox game built with [Rojo](https://rojo.space).

## Development

1. Install the toolchain: `rokit install`
2. Build the place once: `rojo build -o {{NAME}}.rbxl`, and open it in Studio
3. Start syncing: `rojo serve`, then connect with the Rojo plugin
   (`rojo plugin install`, or the Creator Store)

Rojo deletes unknown instances under any `$path` node, so don't keep Studio-only
content there. Read the Output window after every reconnect, before saving or
publishing.

## Structure

- `src/shared` → ReplicatedStorage/Shared: types, config, pure utilities
- `src/server` → ServerScriptService/Server: authoritative game systems
- `src/client` → ReplicatedStorage/Client: rendering, input, UI

## Checks

- Format: `stylua src`
- Lint: `selene src`
- Types: `rojo sourcemap default.project.json --include-non-scripts --output sourcemap.json`, then
  `luau-lsp analyze --sourcemap=sourcemap.json --definitions=@roblox=globalTypes.d.luau src`
  (download `globalTypes.d.luau` as in `.github/workflows/ci.yml`)
```
