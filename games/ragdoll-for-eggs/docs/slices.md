# Ragdoll for Eggs: build slices

Build one slice at a time. After each one: playtest in Studio, fix errors, run the "show your best friend" review, commit, and show the owner what's new. Details are in `brief.md`.

1. **Loading screen + the whole map + the first drop + its tutorial step.**
   - Build the **whole map visibly** (`studio-visible-build`): the Peak, the Drop Edge, and **all 7 zones stacked down the slope**, each with its own theme, plinko pegs and bumpers, a row of egg bins, and a **full-width glass wall gate with its sign** between every two zones. The glass walls are a must-have from slice 1.
   - Gameplay this slice: Zone 1 only. JUMP → server rolls the bin → client ragdoll lands there → egg granted. Bins have no reward logic. The first glass wall bounces the ragdoll back (no Fall Power yet).
   - Tutorial steps 1–2 in spotlight style.
2. **Hatching and pets.** Incubators at the base, hatch reveal cutscenes, pets earning cash every second, the save system, the Index.
3. **Fall Power and smashing the glass gates (zones 2–3 playable).** The ⚡ stat, upgrades, live gate signs with progress bars and pass chance, the glass-shatter smash and the glass bounce animations, zone reveal cutscenes. Tutorial steps 3–4.
4. **Hazards, pass chance, bust bins and shards.** Wipeouts, Grip / Heat Shield / Balance, Shield charges, the odds board reading the shared settings. Tutorial steps 5–6 + reward cutscene.
5. **Monetization.** 2x → 100x Fall Power and Cash, Server Luck, Extra Drops, Auto-Drop, Shields, Gate Smash, Instant Hatch, Starter Pack, idempotent receipts.
6. **Zones 4–7, rebirth and jump styles.**
7. **Social and events.** Shared slope, server and global leaderboards, Jackpot Hour, Low Gravity, Mega Bumpers, Egg Rain, the admin command.
8. **Retention.** Daily rewards, playtime gifts, offline earnings, Season 1 "Drop Pass", group reward, like goal.
9. **Polish and launch.** Mobile pass, performance on a low-end phone, thumbnail and icon, store description, security review.
